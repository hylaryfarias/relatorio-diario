Verificando o painel do time…

Ativar edição

Cole aqui um token do GitHub com permissão de Gists. Ele fica guardado só neste navegador, nunca vai para o repositório, e é o que permite publicar o painel para o time.

  1. Abra github.com/settings/personal-access-tokens/new
  2. Em Token name, escreva painel de depósitos; em Expiration, escolha o prazo que preferir
  3. Em Account permissions, ache Gists e marque Read and write
  4. Clique em Generate token e copie o código que aparece
